Entry for the [make.fun bounty "One Star, Written in Sap"](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4).

`main.py` is deterministic (no network, no randomness) and writes a single
one-line 1-star review from a houseplant about its human owner to
`/output/entry.txt` (176 characters, 1 line, within the 1–279 character gate).

Run it with:

```sh
python3 main.py
```
